Virtual Terminal POS

Payment Processing | Field Service Management | Platform Modernization

Project Overview

Led Business Analysis and delivery coordination for a Virtual Terminal POS platform supporting payment processing, technician scheduling, service management, customer transactions, and accounting integrations.

The initiative involved modernizing a legacy PHP platform into a scalable React and Node.js ecosystem while introducing advanced scheduling capabilities, payment workflow enhancements, QuickBooks integration, and database modernization.

Business Challenge

The existing application was built using a legacy PHP architecture and faced challenges around scalability, maintainability, payment workflow complexity, technician scheduling, and third-party integrations.

  • Legacy PHP architecture limiting future scalability
  • Need for migration to React and Node.js
  • Database modernization from Couchbase to Capella
  • Limited technician scheduling capabilities
  • Lack of full calendar visibility for workforce management
  • Complex refund and partial refund processes
  • Payment workflow enhancements for Consumer Choice and RewardPay
  • Need for QuickBooks integration and accounting automation

Platform Modernization

  • Migration from PHP to React.js and Node.js
  • Modern API-driven architecture
  • Enhanced UI and user experience
  • Improved scalability and maintainability
  • Migration from Couchbase to Capella database
  • Improved system performance and reliability

Scheduling & Workforce Management

Payment Workflow Transformation
